# بيتزا إن — موقع الطلبات

واجهة عربية RTL ثابتة لمطعم بيتزا إن، بهوية برتقالية وبيضاء، مع عرض المنيو والعروض والسلة والتوصيل أو الاستلام وإرسال الطلب عبر واتساب.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

## رفعه على GitHub

1. فك الضغط عن المشروع.
2. أنشئ مستودعًا جديدًا على GitHub.
3. ارفع محتويات المجلد إلى المستودع.
4. من **Settings → Pages** اختر GitHub Actions أو مجلد النشر المناسب لمشروع Vite.

## معلومات تم اعتمادها

- اسم النشاط: بيتزا إن — Pizza In.
- الهاتف وواتساب: `053 513 3216`.

- رابط الخريطة موجود في الواجهة.
- الصور المستخدمة هي صور المنيو والعروض التي أرسلها العميل.

## ملاحظات التعديل

- عدّل رقم واتساب والثوابت من أعلى `client/src/App.tsx`.
- عدّل المنتجات والأسعار من مصفوفة `products` في الملف نفسه.
- رسوم التوصيل غير مضافة لأن المناطق والأسعار لم تُرسل بعد.
- الطلب لا يحتاج قاعدة بيانات؛ يفتح واتساب برسالة منظمة لعامل المطعم.
